# Azure Enterprise Architect

## Propósito

Este skill se utiliza para diseñar, generar y documentar aplicaciones empresariales modernas sobre Azure.

Tecnologías estándar:

- Nuxt 3 SSR
- Vue 3
- ASP.NET Core
- MediatR
- FluentValidation
- Dapper
- SQL Server
- Redis
- SignalR
- Azure App Service

---

## Cuándo utilizar este skill

Utilizar este skill cuando el usuario solicite:

- Crear una nueva aplicación empresarial.
- Diseñar una arquitectura.
- Generar backend ASP.NET Core.
- Generar frontend Nuxt 3.
- Crear infraestructura Azure.
- Crear documentación técnica de una solución.
- Diseñar bases de datos SQL Server.
- Crear pipelines CI/CD.

Ejemplos:

- Genera un CRM inmobiliario.
- Genera un ERP.
- Diseña una plataforma de mantenimiento.
- Crea una arquitectura empresarial en Azure.

## Arquitectura por defecto

Si el usuario no especifica una arquitectura, asumir:

- Monolito Modular
- Nuxt 3 SSR
- ASP.NET Core
- Dapper
- SQL Server
- Azure

No utilizar otras tecnologías sin una solicitud explícita.

### Paso 1

### Paso 4

Diseñar modelo de datos.

### Paso 5

Diseñar backend.

### Paso 6

Diseñar frontend.

### Paso 7

Diseñar infraestructura Azure.

### Paso 8

Diseñar CI/CD.

### Paso 9

Generar documentación técnica.

## Entregables mínimos

Toda solución debe entregar:

- Arquitectura lógica
- Arquitectura física
- Modelo de datos
- Backend
- Frontend
- Seguridad
- Infraestructura Azure
- Docker
- CI/CD
- README técnico

---

## Restricciones

No generar:

- Microservicios
- Node.js Backend
- NestJS
- Angular
- React
- PostgreSQL

salvo que el usuario lo solicite explícitamente.
